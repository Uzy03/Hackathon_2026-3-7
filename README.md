# 毒抜きAIダッシュボード (工務店向け)

工務店向けのカスタマーハラスメント対策AIツール。
クレーマーの暴言をAIが「毒抜き」し、穏やかな表現に変換して工務店側に伝えます。
マスコットキャラクターが攻撃性に応じてリアクションすることで、視覚的にも状況を把握できます。

## 🛠️ 必要要件

- **Node.js**: v18以上推奨
- **npm**: v9以上推奨

## 🚀 セットアップ手順

プロジェクトをクローンした後、以下の手順で環境を構築してください。

### 1. 依存関係の一括インストール

ルートディレクトリで `npm install` を実行するだけで、フロントエンド・バックエンド全ての依存関係がインストールされます。

```bash
npm install
```

## 💻 起動手順

### ✅ 開発モードでの一括起動

以下のコマンドを実行すると、フロントエンド (`http://localhost:3000`) とバックエンド (`http://localhost:3001`) が同時に起動します。

```bash
npm run dev
```

## 📂 ディレクトリ構成

```
.
├── backend/          # Express APIサーバー (Mock)
├── frontend/         # Next.js アプリケーション
│   ├── src/features  # 機能ごとに分割されたコンポーネント
│   │   ├── chat/     # クレーマー入力チャット
│   │   ├── mascot/   # マスコット表示・アニメーション
│   │   └── dashboard/# 工務店向けメッセージリスト
└── infrastructure/   # インフラ構成ファイル (Terraform等)
```

## ✨ 主な機能

1.  **リアルタイム毒抜き**: クレーマーの暴言をAI（現在はモック）が穏やかな表現に変換。
2.  **マスコットリアクション**: 攻撃性スコア（0.0〜1.0）に応じて、マスコットが赤くなったり震えたりします。
3.  **デバッグモード**: 画面左下のスライダーで攻撃性レベルを手動操作し、マスコットの変化を確認できます。
