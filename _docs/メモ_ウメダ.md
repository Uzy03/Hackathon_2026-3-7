# キャラクターの動作技術について
このキャラクターは、次のようなフロントエンド技術で動いています。

React / Next.js + TypeScript
page.tsx で MascotDisplay コンポーネントを呼び出し、aggressionLevel（攻撃性レベル）という数値状態を useState で管理して、その値を渡しています。
- Reactコンポーネント + カスタムフック
MascotDisplay.tsx でキャラクターを描画し、useMascotState フック（useMascotState.ts）で
  - 色 (color)
  - 震えの強さ (shakeIntensity)
  - 涙の有無 (isCrying)
を aggressionLevel から計算しています（useMemo でメモ化）。
- SVGによる2D描画
キャラクター自体は <svg> と <circle>, <path> などの SVG要素 で描画されています。3DエンジンやCanvas/WebGLではなく、ブラウザ標準のSVGです。
- CSSトランジション & Tailwind CSS
背景色やサイズ変更などは Tailwind CSS のクラス（transition-colors, duration-500 など）でアニメーション、
震えは transform: translate(...) をインラインスタイルでランダムに変えて、「プルプル」しているように見せています。
まとめると、「Next.js + React（TypeScript）で状態管理し、その値に応じて SVG と CSS（Tailwind）を動的に変えることでキャラクターを動かしている」、という構成です。


# キャラクターのストレス値の実装について

- 外部APIを利用する（最も高精度で簡単）
Googleが提供している Perspective API や、OpenAIのModeration API（に加えてGPTでのスコアリング）を使う方法です。
特にPerspective APIは、不適切な発言を「確率」として数値（0.0〜1.0）で返してくれるため、そのまま100倍してスコアに使えます。

実装イメージ (backend/src/services/purifyService.js)
// OpenAIを使った例：プロンプトで数値を指定させる
const getToxicityScore = async (text) => {
  const response = await openai.chat.completions.create({
    model: "gpt-4o-mini",
    messages: [
      {
        role: "system",
        content: "入力された文章の攻撃性や不快指数を0(クリーン)から100(猛毒)で判定し、数値のみを返してください。"
      },
      { role: "user", content: text }
    ],
  });
  return parseInt(response.choices[0].message.content);
};
